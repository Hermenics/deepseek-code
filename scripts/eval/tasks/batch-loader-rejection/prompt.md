`BatchLoader` in `src/batchLoader.ts` collects the `load(key)` calls made in the same tick and fetches them with one `batchFn(keys)` call. When `batchFn` rejects, every caller in that batch hangs forever, and a key whose result came back as an `Error` stays failed for good. Make every caller in a failed batch reject with the batch's error, never cache a failure (the next `load` of that key fetches it again), and keep caching successful results. Add tests for this behavior.
